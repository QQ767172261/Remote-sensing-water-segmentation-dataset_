# 遥感水体分割数据集
## 数据集基础信息表
|项目|详情|
| ---- | ---- |
|数据集名称|遥感水体分割数据集|
|数据1（RGB）|高分二号（Gaofen2）8bit三通道RGB影像；7000余张；分辨率1024×1024；mask掩码标注；数据体积16GB|
|数据2（多光谱）|高分二号（Gaofen2）16bit四通道RGB+NIR影像；8000余张；分辨率1024×1024；mask掩码标注；数据体积65GB|
|标注方式|像素级mask掩码语义分割标注|
|影像来源|高分二号卫星遥感影像|

## 公众号摘要
本遥感水体分割数据集包含两套高分二号卫星影像，一套为8bit三通道RGB图像7000余张，另一套为16bit四通道RGB+NIR多光谱图像8000余张，图像尺寸均为1024×1024，全部采用mask掩码做像素级语义分割标注。多光谱数据融合近红外波段，对水体识别敏感度更高，适合训练遥感水体提取语义分割模型，可用于河湖岸线提取、水域动态监测、洪水淹没范围识别、水资源调查等遥感解译任务。

## 数据集应用价值
1. **双版本可选**：RGB可见光版本适合普通可见光分割模型；RGB+NIR四通道多光谱版本利用近红外波段，水体与陆地区分效果更强，适配多光谱遥感模型。
2. **高分辨率**：1024×1024高分二号卫星影像，细节丰富，可捕捉细小水体、支流、滩涂。
3. **像素级mask标注**：标准语义分割掩码标注，可直接用于Unet、Segformer、YOLO-seg等分割网络训练。
4. **行业落地支撑**：支撑水资源动态监测、河道岸线变迁分析、洪水灾害快速评估、湿地保护、国土水体资源普查等工程应用。
